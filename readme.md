# NisheshChauhan_Task(12)

This is a simple web project that shows how JavaScript can be used to calculate compound interest. The page includes a basic HTML structure, a little CSS styling, and a small script that computes the result for a sample amount.

## What it does??
- Calculates compound interest using a fixed principal amount, rate, and duration
- Displays the result through JavaScript console output
- Keeps the design minimal and easy to understand

## How to run??
- Open the index.html file in your browser to see the project.
- Go to inspect > console tab and see the outputs.
- or go through the deployed GitHub link and repeat the step 2.
